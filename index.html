SEARCH & RESCUE · ACOUSTIC DATASET

SAR-AudioData

A sound event detection dataset for disaster and emergency search-and-rescue scenarios. It focuses on calls for help and knocking sounds made by trapped people, and provides real UAV (drone) noise together with multiple noise-augmented versions, for training and evaluating sound event detection models under heavy noise.

Request the dataset Listen to samples

Background

At disaster sites such as earthquakes and building collapses, trapped people often call out or knock on pipes and walls to signal for help. Airborne search using UAV-mounted acoustic arrays is an efficient approach, but the strong noise from the rotors can severely mask these faint distress signals.

🆘

Call-for-help detection

Real human distress-voice samples, used to recognize spoken calls for help from trapped people and support life-detection tasks.

🔨

Knocking-sound detection

Rhythmic knocking sounds produced by striking pipes, walls and other hard objects — an important distress cue beyond speech.

🚁

UAV-noise robustness

Real rotor noise under various flight states, plus synthesized noise-augmented samples, used to improve model robustness against noise.

Dataset overview

The dataset contains raw recordings, class-separated training data and multiple augmented versions, all accompanied by event-level JSON time annotations.

Call for help
687 original · with 3×/6× augmentation
Knocking
1259 original · with 3× augmentation
UAV noise
Real recordings under various flight states
Noise augmentation
Mechanical / wind / white noise + UAV noise

Annotation format

Each audio file has a JSON annotation file of the same name, using event-level time intervals.

FieldTypeDescription
start_timefloatEvent start time (seconds)
end_timefloatEvent end time (seconds)
labelstringEvent class (call for help / knocking)
durationfloatEvent duration (seconds)
 
[
  {
    "start_time": 0.691,
    "end_time": 1.920,
    "label": "呼救声",
    "duration": 1.229
  }
]

Note: label values in the annotation files are the original Chinese strings 呼救声 (call for help) and 敲击声 (knocking).
