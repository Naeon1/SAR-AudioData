SAR-AudioData 搜救声学数据集

面向灾害与应急搜救场景的声音事件检测数据集，聚焦被困人员发出的呼救声与敲击声，并提供真实无人机噪声及多种加噪增强版本，用于在强噪声环境下训练与评估声音事件检测模型。

申请下载数据集 试听示例数据

项目背景

在地震、建筑坍塌等灾害现场，被困人员往往通过呼喊或敲击管道、墙体来求救。无人机搭载声学阵列进行空中搜救是一种高效手段，但螺旋桨产生的强噪声会严重淹没微弱的求救信号。

🆘

呼救声检测

采集真实人声呼救样本，用于识别被困者的语音求救信号，支撑生命探测任务。

🔨

敲击声检测

采集敲击管道、墙体等硬物产生的规律性敲击声，作为语音之外的重要求救线索。

🚁

无人机噪声鲁棒性

提供多种飞行状态下的真实螺旋桨噪声，并合成加噪样本，用于提升模型抗噪能力。

数据集概览

数据集包含原始采集音频、按类别分离的训练数据以及多种数据增强版本，全部附带 JSON 事件级时间标注。

标注格式

每条音频对应一个同名的 JSON 标注文件，采用事件级时间区间标注。

字段类型说明
start_timefloat事件开始时间（秒）
end_timefloat事件结束时间（秒）
labelstring事件类别（呼救声 / 敲击声）
durationfloat事件持续时间（秒）

  {
    "start_time": 0.691,
    "end_time": 1.920,
    "label": "呼救声",
    "duration": 1.229
  }
